# LocalPress releases

Downloads for [LocalPress](https://localpress.dev), local WordPress development
for Linux.

**[Download the latest version →](https://github.com/wearelinearuk/localpress-releases/releases/latest)**

## Install (Fedora)

```sh
sudo dnf install ./LocalPress-aarch64.rpm
```

Or double-click the file to open it in GNOME Software. Podman is installed
automatically if you don't have it. See [localpress.dev](https://localpress.dev)
for guides and FAQs.

Already installed? LocalPress checks for updates when it starts and offers to
restart when a new version is ready.
